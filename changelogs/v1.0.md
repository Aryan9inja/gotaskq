# GoTaskQ v1.0

Release date: 2026-04-28

## Summary
GoTaskQ v1.0 is a stabilization release with small but important fixes plus a recorded stress-test baseline. It resolves a Redis Lua status-update compatibility issue, speeds the logger handler for faster processing, and documents current runtime metrics behavior under load.

## Changes
- Fixed Redis Lua job status update script to avoid global variables, improving compatibility with newer Redis versions.
- Reduced `logHandler` sleep time to 1ms for faster job processing.
