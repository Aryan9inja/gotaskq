# v1.1 - library addition

## Overview
Version 1.1 marks a significant milestone in the GoTaskQ project with the introduction of a fully-fledged library for the Go ecosystem. This release focuses on providing a clean and flexible API for embedding GoTaskQ into other applications, while maintaining the existing HTTP server implementation as a reference for custom integrations.

## Key Changes
- **Library Introduction:** The core functionality of GoTaskQ is now available as a library that can be imported into Go projects. This allows developers to integrate job queue capabilities directly into their applications without the need for an HTTP server.
- **HTTP Server as Reference:** The existing HTTP server implementation remains intact and serves as a reference for users who want to build custom servers or use the library in a standalone manner.
- **Flexible and Extensible Design:** The library is designed to be flexible, allowing users to implement their own storage backends, scheduling algorithms, and worker models as needed. This extensibility ensures that GoTaskQ can be adapted to a wide range of use cases and application architectures.

## Benchmarks
The introduction of the library does not impact the core performance of GoTaskQ. The benchmarks from version 1.1 remain relevant, demonstrating robust multi-queue support and efficient job processing with both in-memory and Redis backends.
